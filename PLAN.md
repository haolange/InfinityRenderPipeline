## Locked design decisions

### Resources, failure and configuration

- Declare every shader-consumed resource as explicit pass RG input. Remove Atmosphere/ZBin recording-time global prebinding; consumers bind through command capability interfaces. Keep async compute with correct synchronization.
- `RGBuilder.Execute` propagates the original exception. Failing cameras roll back pending history/cache and cannot be marked successful. Already queued GPU work cannot be undone; retain necessary frame-end Submit and deferred retirement, including exception paths.
- RP Asset `volumeProfile` is the sole default Volume source. Validate required components/parameters at pipeline creation. Delete CombineLUT runtime hardcoded fallbacks. Inactive scene Volume inherits the valid default configuration.
- Shader/kernel capability validation occurs during record/setup. Missing required producers fail directly. Optional paths record only when the single capability decision permits them. Verification must demonstrate an enabled, functioning feature; pass skipping is not acceptance.

### Material routes and layers

- `_SurfaceRoute` and `_TranslucentStage` solely determine material routes. Editor pass-enable, runtime material updates and MeshDraw eligibility share one parser. Replacing a shader invalidates its pass cache.
- Store the 8-bit surface rendering layer in `GBufferC.a`, without another MRT. Unity Renderer uses its own rendering-layer data; Infinity's public mask remains eight bits.
- Instance record owns Infinity Mesh layer data. Transform/Instance exclusivity permits a transform-indexed GPU layer buffer. Cover create/free/rollback/slot reuse/dirty upload; do not introduce a second compacted layer configuration chain.
- `lightLayer` filters surface direct lighting only. `shadowLayer` independently filters casters. `enableVolumetric` remains the volume-light switch.
- Explicitly migrate Unity `uint.MaxValue` (Everything) to `0xFF`; other unknown high bits fail scene/build validation, rather than silently truncate or hide geometry.

### SSS and actual super resolution

- Keep diffuse separate from specular/emissive. Scatter only diffuse; recompose a new canonical `LightingBuffer` before Forward. Atmosphere, pyramids and screen-space consumers read the final owner.
- Volume `NumSamples` is the only SSS quality source; remove the duplicate RP Asset field. RP Asset still owns diffusion profiles. SSS requires Deferred; reject Forward+SSS contradictions.
- `enableSuperResolution` selects the mode. Add fixed `renderScale` in [0.5,1.0], default 1.0, affecting Game cameras only when SR is enabled.
- One per-camera frame dimension descriptor owns internal/display dimensions. Internal dimensions are `ceil(displaySize * renderScale)`, at least 1. Geometry and screen-space inputs use internal size. SR histories, post and display output use display size.
- Game chooses SR when enabled. SceneView/Preview stay native size with TAA and continuity gating. TAA and SR are mutually exclusive.
- SR consumes motion/depth/reactive mask/jitter. Scale/size/mode/continuity changes reset history. Overlays/Gizmos needing display-sized depth use a separate Raster depth resolve.
- Preserve live Halton jitter capability while separating sampling from the former Generator's responsibility. Preview first/intermittent renders reset history without jitter; only continuous rendering accumulates.

Unify Runtime, Editor and required assembly identities as Infinity. Update references, friend assemblies, incorrect versionDefine package identities and serialized type names. Do not retain old-identity shims or compatibility attributes.

Before renaming, enumerate affected `SerializeReference`, `m_EditorClassIdentifier` and binary asset types. Never text-replace binary assets. If reconnection and idempotence cannot be established on copies, stop that migration before renaming and list the specific assets. Save only affected objects. Prove zero missing scripts, zero unconverted old identities and preservation of pre-existing user edits.

### Numeric and image gates

- Any raw GPU NaN/Inf fails. Do not replace invalid values in shaders, capture or statistics to pass.
- Exercise `1x1`, `17x13`, `1919x1079` and normal window dimensions.
- For static temporal fixtures, establish live redraw first, warm up at least 120 frames, then capture at least three normal beauty frames. With per-channel threshold `8/255`, changed-pixel ratio in the predeclared static ROI must be below `0.5%`.
- Stable valid regions have confidence >0.9. Disocclusion/cut/reset cases demonstrate rejection and recovery. Do not require all static pixels always below 1 or manufacture constant confidence.
- Moving/revealed/transparent regions have dedicated fixtures, not the static-difference gate. Fix ROIs before the run; never exclude failed pixels afterward.
- Validate Film/LUT separately from transfer functions. Only a known linear OETF test uses `0.18 -> sRGB approximately 0.461356`; arbitrary Film/IBL/exposure gray cards do not inherit that target.
- Retire the sun/sky gate inferred from SkyView without a solar disc and the unreferenced fixed horizon ratio. Keep numeric observations, judge atmosphere against fixed inputs and an independent reference.
- With HardwareSRGB, `DisplayColorBuffer` readback is pre-encoding linear, not actual encoded sRGB backbuffer data. Verify hardware encoding contract, real Game/Player image and actual format separately.
