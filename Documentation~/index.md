# Infinity RP

InfinityRP is a RenderGraph-native Scriptable Render Pipeline. These pages describe authoring. The implementation is [ARCHITECTURE.md](../ARCHITECTURE.md). Contributor rules are [AGENTS.md](../AGENTS.md). Verification state is [Docs/FeatureStatus.md](../Docs/FeatureStatus.md).

Editor windows use Unity Editor styles. This manual describes their behavior. It is not a visual design system.
